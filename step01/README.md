# 01 — Call an LLM

## Discover

A coding agent starts as an ordinary model call. In this milestone, the code
uses a local Ollama model by default and prints one live response.

The question is embedded directly in the prompt — there is no agent loop and
the model is not asked to propose an action. It simply reads the question and
answers it. The task is a Winograd Schema Challenge question (Hugging Face
dataset: `winograd_wsc`, config `wsc273`): a sentence with an ambiguous
pronoun that requires common-sense reasoning to resolve. step02 asks a cloud
model the exact same question (`WSC_QUESTION`) the same way, so you can
compare a local model's answer against a cloud model's answer.

Default local settings used by `agent.py`:

- `OLLAMA_HOST=http://localhost:11434`
- `OLLAMA_MODEL=qwen3:0.6b`
- `OLLAMA_API_KEY=` (empty for local Ollama)

## Virtual Environment Setup (required)

Create a dedicated virtual environment for this task in `minicoder/step01`.
Prefer one independent `.venv` per step folder so each task keeps its own
dependencies isolated.

Run from this folder: `minicoder/step01`.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Before running this step, make sure you've completed the checks in
[../SETUP.md](../SETUP.md): Ollama installed and running, and the
`qwen3:0.6b` model pulled.

This step also creates the shared `.env` file used by all three steps. From
the `minicoder/` repository root:

```bash
cp .env.example .env
```

The defaults in `.env` (`OLLAMA_HOST`, `OLLAMA_MODEL=qwen3:0.6b`) already
match this step, so no edits are required here. step02 and step03 will use
the `OPENROUTER_*` values in the same file.

## Testing

Deterministic unit test (fake client, no live model call):

```bash
.venv/bin/python -m pytest -q test_agent.py
```

Live local-Ollama test (non-deterministic content):

```bash
RUN_LIVE_OLLAMA_TEST=1 .venv/bin/python -m pytest -q test_agent.py
```

The live assertion only checks that a non-empty string is returned from the
LLM, not exact wording.

## Run The Milestone Script

```bash
.venv/bin/python agent.py
```
